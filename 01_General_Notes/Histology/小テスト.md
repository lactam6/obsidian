## #1 総論
- In situ hybridizationの原理
	- 組織や細胞の形態を保ったまま特定のDNA, RTAの局在を可視化する技術
	- 組織切片上のmRNAに、相補的な塩基配列を持つ標識プローブをハイブリタイズさせ、結合を検出する
![[Pasted image 20251210155956.png]]
- 電子顕微鏡の種類とその原理
	- 透過型電子顕微鏡
		- 電子線を薄い切片に透過させ、電子の透過度の差を像にする
		- 細胞内小器官などの内部構造を高解像度で観察
	- 走査型電子顕微鏡
		- 電子線を表面に走査
		- 放出される二次電子を検出して立体的な表面構造を観察
- 遺伝子の組織レベルでの発現様式を調べる方法
	- in situ hybridization: mRNAの局在を可視化する
	- 免疫染色: 遺伝子産物に対する特異抗体を用いて組織切片を染色、発色・蛍光でタンパク質の局在分布を観察
- その他の手法
	- 一般染色: 化学反応を利用する
	- GFP融合タンパク質(遺伝子導入): 目的タンパク質をGFPと融合させた遺伝子導入を行う。生きた細胞内で局在を追跡可能
- 組織の分類
	- 上皮組織: 体表や管腔の内面を覆い、保護、吸収、分泌をおこなう
	- 結合組織: 細胞外基質が豊富で、結合、物質交換を行う
	- 筋組織: 筋肉の収縮によって運動を生む
	- 神経組織: ニューロンとグリアからなる、情報の受容、伝達、統合を行う

## #2 上皮
- 移行上皮
	- 尿路で見られる上皮
	- 進展に応じて形が変化する
		- 収縮時: 多層で表層細胞が丸い
		- 伸展時: 薄く扁平
- 上皮の頂上面(外界側)の特徴的な構造
	- 上皮組織の種類による
	- 微絨毛や不動毛、繊毛が発達
- 上皮の側面に存在する特徴的な構造: 接着複合体
	- 密着結合(閉鎖帯)
		- 隣接細胞の膜を密着させ物質の通過を遮断する
	- 接着帯
		- カドヘリンを介した細胞同士の密着
		- アクチン繊維と連結する
	- デスモソーム(接着斑)
		- 強固なスポット状の接着
		- 中間径フィラメントと連結する
- 上皮の基底膜面(組織側)に存在する特徴的な構造:基底膜が存在
	- 基底膜
		- 厚みと裏表のある膜
		- 防御、物質産生、物質の出入り
	- ヘミデスモソーム
		- 細胞と基底膜を連結させる
		- 中間径フィラメントと連結する
	- 局所接着
		- アクチンフィラメントの末端とインテグリンをつなぐ
		- リン酸化されてシグナルを体内に伝える

## #3 腺
- 外分泌腺の発生
	- 上皮が内側に入り込むことで作られる
	- 貫入した上皮と表面との管がそのまま残り、分泌いつ物を表面に流す
	- 唾液腺、汗腺
- 内分泌腺の発生
	- 上皮が内側に入り込むことで作られる
	- 勧誘の後表面との連絡が失われ、細胞の集まり(腺索)から血管へ直接ホルモンを分泌する
	- 甲状腺、副腎
![[Pasted image 20251210162656.png]]
- 複合線の組織構造
	- 葉間導管: 重層円柱
	- 葉
		- 小葉間導管: 多列円柱
		- 小葉
			- 小葉内導管: 立法~円柱
			- 腺房: 単層+筋上皮
				- 介在部(小): 扁平上皮 => 線状部(大): 立方上皮
![[Pasted image 20251210162846.png]]
- 腺の分泌様式
	- 外分泌腺
		- エクリン(メロクリン): 細胞を壊さずに顆粒のみ開口分泌
		- アポクリン: 細胞頂部がちぎれて放出
		- ホロクリン: 細胞全体が崩壊して分泌
	- 内分泌腺: 管を介さず血管へ直接分泌
	- 傍分泌(パラクリン): 血液に乗らず、近所の細胞へ分泌
	- 自己分泌(オートクリン): 出した物質を自分自身で受け取る
![[Pasted image 20251210164542.png]]
- 上皮の発生
	- 内胚葉由来: 表皮、神経上皮、口腔や肛門などの上皮
	- 中胚葉由来: 血管内皮、中皮(胸膜、腹膜)
	- 外胚葉由来: 消化管上皮、呼吸器上皮(気管、肺)

## #4 結合組織1
- 疎性結合組織: 繊維と基質がゆるく配置された結合組織で、皮下や粘膜下に多い。物質交換や炎症反応の場になる
	- 細胞
		- 線維芽細胞
		- 免疫細胞
			- マクロファージ
			- 肥満細胞
			- リンパ球
	- 繊維
		- コラーゲン繊維
			- 最も豊富
			- 強い引張強度を持つ
			- 組織を支持
		- 弾性線維
			- 伸び縮み可能
			- 血管壁や靱帯などの弾性に寄与
		- 細網線維
			- 細いコラーゲン繊維(III型)
			- 網目状に細胞を支える
			- リンパ節、骨髄などに多い
	- 基質
		- 水分の多い基質
			- プロテオグリカン
			- 糖タンパクなど
![[Pasted image 20251210165336.png]]
- コラーゲン分子の構造
	- 長さ300nm, 径1.5nm
	- a鎖が3本右回りに巻き付いた3重らせん構造
	- a1鎖とa2鎖の典型的配列はグリシン、プロリン、ヒドロキシプロリンなどからなる
	- ヘテロ三量体 => I型
	- ホモ三量体 => II型
![[Pasted image 20251210165603.png]]
- プロテオグリカン
	- 中心タンパク質に多数のグリコサミノグリカン鎖が結合した巨大な分子
	- 水分を強く保持
	- 機能
		- 周囲の細胞の支持、保護
		- 圧力吸収
		- 分子の拡散、シグナル分子の保持

# #5 結合組織2
- 疎性結合組織内に定住している細胞
	- 肥満細胞: ヒスタミンなどの顆粒を持ち、アレルギー反応に関与する
	- 線維芽細胞: 繊維や基質を作る主な細胞。長い紡錘形で卵型
	- 脂肪細胞: 脂肪を蓄え、エネルギー貯蔵、保温、緩衝。トリグリセリドを合成、貯蔵する働きがある
		- 単胞性脂肪細胞: 大きな脂肪滴を1つ持ち、大きな球形を有する
		- 多胞性脂肪細胞: 小さな脂肪滴を多数持ち、小型で多角形の形を呈する
	- マクロファージ: 異物の貪食や免疫応答の調節
	- (周皮細胞): 血管平滑筋などに分布する間葉系の幹細胞で、基底膜に挟まれる
- 白血球の種類
	- 顆粒球
		- 好中球 (多)
			- 分葉しがち
			- 好中性の小型の顆粒
		- 好酸球 (中)
			- アレルギー反応や寄生虫感染の防御
			- ギムザ染色により赤く染まる大型の特殊な顆粒
		- 好塩基球 (少)
			- 核は2つまたはそれ以上に不規則に分葉
			- 暗紫色に染まる他大型の好塩基性の顆粒
	- 無顆粒球
		- 単球
			- マクロファージに分化
			- 免疫における抗原提示細胞
			- 不定形の細胞
		- リンパ球
			- リンパ系、免疫系で働く細胞
			- 核が球形

## #6 結合組織3
- 軟骨の種類
	- 硝子軟骨: 肋軟骨、関節軟骨、気管
	- 弾性軟骨: 咽頭蓋、耳介
	- 線維軟骨: 椎間円板、恥骨結合
- 骨のリモデリング: 破骨細胞と骨芽細胞の働き
	- 破骨細胞: 骨吸収: 古い骨を吸収
	- 骨芽細胞: 骨形成: 新しい骨基質を沈着させて再形成
	- 効果: 骨の強度維持、微小損傷の修復、カルシウム代謝の調節
- 骨化の様式
	- 膜内骨化: 頭蓋骨の一部、鎖骨などの平板骨
		- 間葉系細胞から直接骨芽細胞が分化して骨が形成
	- 軟骨内骨化: 四肢
